# Help us writing tips and documentation

Do you think something is missing or wrong on these pages? You can submit changes to them! There are direct "Edit page" buttons on each page or you can access the [GitHub repo](https://github.com/HexlinkSocial/hexlink-docs) directly

Not technical? Email us at [feedback@hexlink.org](mailto:feedback@hexilnk.org) and we'll add it for you!

You'll probably find something to talk about while reading but here's some ideas what you could add:
- Your experience on what works and doesn't work when making and keeping friends
- Tips on managing the chat
- Event ideas
- Wellbeing and safeguarding tips
